## 🔍 Problem Summary

OpenAI Projects lack persistent memory of actual project file structure (user-local), leading to:

1. Regeneration of code modules that already exist (e.g. CLI scripts recreated and overwritten multiple times).
2. Creation of over-complex tooling (e.g. validators, launchers, bots) when users are asking for practical deployment solutions.
3. Breaking of previously working features due to loss of awareness of prior implementations.
4. A mismatch between what the user sees (index, folders, files) and what the AI assumes is true.
